# Слоты Prenot@mi — Белград

Одностраничный сайт канала [@italy_belgrade_slots](https://t.me/italy_belgrade_slots):
бот сообщает о появлении свободных слотов на шенгенскую визу в консульстве
Италии в Белграде (портал Prenot@mi).

Статика для GitHub Pages. Адрес: https://sloty.veridok.ru/

| файл | что это |
|---|---|
| `index.html` | страница: счётчик дней без выкладки, описание, вопросы-ответы, две кнопки в канал |
| `privacy.html` | политика обработки данных (форм на сайте нет, собирается только веб-аналитика) |
| `smoke.js` | прибор замера: счётчик Метрики 113161887 и функция `track()` |
| `robots.txt`, `sitemap.xml` | для поисковых роботов; трафик только органический |
| `favicon.svg`, `.nojekyll` | обвязка |

Цели Метрики: `tg_click_top`, `tg_click_bottom` — клики по верхней и нижней
кнопке подписки. Разные, чтобы видеть, подписываются сразу или после чтения.

Сайт не связан с МИД Италии, посольством Италии в Белграде и порталом
Prenot@mi. Запись на приём предоставляется консульством бесплатно.
